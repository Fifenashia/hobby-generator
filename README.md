# The Hobby Generator

**A brain-friendly hobby generator for when choosing feels hard.**

The Hobby Generator is a web application designed to help curious, creative, and easily overwhelmed brains discover new hobbies without the pressure of figuring out where to start.

Whether you're looking for something quick, inexpensive, relaxing, or completely unexpected, the goal is simple: make exploring new interests easier and more accessible.

## Current Features

- Randomized hobby suggestions using the Fisher-Yates shuffle algorithm
- Category-based filtering
- Time-based filtering
- Hobby information stored in an external JSON file
- Beginner-friendly activity suggestions
- Simple web interface built with HTML, CSS, and JavaScript

## Why I Built This

I love hobbies. Learning new skills, exploring creative interests, and discovering something unexpected are some of my favorite things.

But sometimes having endless possibilities makes choosing what to do surprisingly difficult.

I wanted to create something that makes that decision easier, especially for people with ADHD or anyone who experiences decision fatigue.

The Hobby Generator is about curiosity without pressure. You don't have to master something, finish a project, or turn every interest into a lifelong commitment.

Sometimes trying something new is enough.

## Running Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using a local development server, such as the Live Server extension.
4. Select your preferences and click **Find 3 Hobbies**.

A local server is required to load the external JSON data through `fetch()`.
